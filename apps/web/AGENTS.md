# apps/web

React + JavaScript single-page app built with Bun (ADR-115). There is no Next.js: no framework runtime, no server components, no file-system routing.

- **Toolchain:** Bun is the package manager (`bun.lock`), bundler (`Bun.build`), dev server and script runner. The pinned version is in `package.json` (`packageManager`), `.bun-version`, `.github/workflows/ci.yml` and `infra/docker/api.Dockerfile`; change all four together. The Playwright runner (`bunx playwright test` resolves to its Node shebang) and `capture:readme` run on Node because Playwright does not support Bun as a runtime.
- **Commands:** `bun install --frozen-lockfile --ignore-scripts`, `bun run build` (the only build command; writes `out/`), `bun run test`, `bun run test:e2e`, `bun run dev` (rebuilds on save, serves `out/` on `PORT`, default 3000), `bun run build:embed` (build and copy into the Go binary's `internal/webui/assets`).
- **Entry:** `app/main.js` imports the CSS, then hydrates (or renders, for the empty redirect pages) `app/App.js` into `#root`. `App` mounts the providers once and swaps only `RouteView`, so providers never remount on navigation.
- **Routes:** `app/routes.js` maps a path to its page component; `app/lib/siteMeta.js` holds each route's title and description, the shared social/PWA head data, and the two redirects (`/actions`, `/reviews`). Adding a page means adding it to both, as `app/<name>/page.js`.
- **Router:** `app/router/` is a small in-house router: `Link`, `usePathname`, `useSearchParams`, `useRouter`, `navigate`. It patches `history.pushState/replaceState` so existing code that calls them updates `useSearchParams`. `useSearchParams` renders on the client only; wrap its consumers in `Suspense` so the prerender shows the fallback.
- **Build output:** `scripts/build.mjs` bundles one hashed script and one hashed stylesheet into `out/assets/`, copies `public/` and `scripts/og/opengraph-image.png` (served as `/opengraph-image`), and prerenders one `<route>.html` per route plus `404.html` with `react-dom/server`, baking each route's head from `siteMeta` (`scripts/lib/document.mjs`). The Go handler serves `assets/` as immutable and everything else per `internal/webui/webui.go`.
- **Tests:** `bun test tests/` holds unit tests that call functions or check rules computed from real files (colour contrast from tokens, manifest and service worker validity, migrations against labels); `tests/site-build.test.mjs` builds the site and checks every page head. Do not write a test that reads application source and regex-matches it. Browser behavior is tested on the Playwright runner under `e2e/` (ADR-119): `e2e/app` (rendered behavior, desktop and mobile projects), `e2e/responsive` (all four viewport projects), `e2e/widths` (own viewports, plus WebKit date fields), `e2e/motion` (timing), `e2e/visual` (`toHaveScreenshot()`, Linux-only, baselines via `bun run test:visual:update`). `e2e/support` holds the `/api/v1/**` mock fixture and datasets; every test gets its own copy of mutable data and a fixed clock (2026-09-07 10:00 Asia/Jakarta).
- No code comments; `node scripts/check-comments.mjs` enforces it.
